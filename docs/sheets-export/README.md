# クロス分析 → 収支表 連携

クロス分析の結果画面で「スプレッドシートに反映」を押すと、表示中の期間の人数が
収支表の「LINE日別_<分析名>」シートに日別で書き込まれます（同じ日付は上書き）。

## 初期設定（1回だけ）

1. 収支表を開き「拡張機能 > Apps Script」→ `Code.gs` の中身を貼り付けて保存
2. 「プロジェクトの設定 > スクリプト プロパティ」に `SECRET` = 任意の長い文字列 を追加
3. 「デプロイ > 新しいデプロイ > ウェブアプリ」
   - 実行ユーザー: 自分 / アクセスできるユーザー: 全員
   - 出てきた URL（`https://script.google.com/macros/s/.../exec`）をコピー
4. worker にシークレットを登録してデプロイ
   ```
   cd apps/worker
   npx wrangler secret put SHEETS_WEBHOOK_URL     # 3 の URL
   npx wrangler secret put SHEETS_WEBHOOK_SECRET  # 2 の文字列
   pnpm run deploy
   ```

## シートの形

| 日付 | 郵送（菖蒲）×離脱 | 郵送（菖蒲）×成約 | 郵送（菖蒲）（合計） | … |
|---|---|---|---|---|
| 2026/11/01 | 1 | 1 | 2 | … |

列名は「軸1グループ名×軸2グループ名」と「軸1グループ名（合計）」。
グループ名を変えると別の列として右端に追加されるので、名前は固定して使ってください。

## 会員数シートからの参照例

11/1〜11/5 の郵送（菖蒲）の友達登録数（列 D が「郵送（菖蒲）（合計）」の場合）:

```
=SUMIFS('LINE日別_MacBook'!D:D, 'LINE日別_MacBook'!$A:$A, ">="&DATE(2026,11,1), 'LINE日別_MacBook'!$A:$A, "<="&DATE(2026,11,5))
```
